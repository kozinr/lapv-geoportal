# LAPV – interaktivní geoportál

Statická webová aplikace (Leaflet + Plotly.js) pro 61 povodí LAPV a klimatické scénáře. Obsahuje mapu OpenStreetMap, GeoJSON vrstvy, interaktivní výběr lokality a graf s pásy 25.–75. percentilu. Vytvořeno v rámci výzkumného projektu SS02030027 Vodní systémy a vodní hospodářství v ČR v podmínkách změny klimatu (www.centrum-voda.cz).
